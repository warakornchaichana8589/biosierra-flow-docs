ช่วงที่ 1

ก่อนมาถึงใบตวงสาร — 2 เส้นทางต้องพร้อมทั้งคู่

A. เอกสาร + สูตร → ได้ "คำสั่งผลิต (SO)"

CR Form → ใบเสนอราคา
ฝ่ายขาย → CR Form, ใบเสนอราคา
ฝ่ายขาย
สูตร / BOM → Test Run → Product Spec
R&D → สูตร / BOM, Test Run, Product Spec
R&DQC ลงนาม Test Run
ใบส้ม (FM-PD-21)
ฝ่ายขาย → ใบส้ม · อนุมัติ 4 ระดับ + บัญชียืนยันรับมัดจำ
ฝ่ายขาย
คำสั่งผลิต (SO) + BOM จากสูตร
ฝ่ายผลิต → คำสั่งผลิต (SO), ปฏิทินการผลิต, แผนผลิต
ฝ่ายผลิต / Planning
BOM ของ SO นี้แหละที่ใบตวงสารดึงไปเติมรายการวัตถุดิบ + ค่ามาตรฐานต่อถังให้อัตโนมัติ

B. วัตถุดิบ (RM) → มาถึงห้องผลิต

ใบขอซื้อ (PR) → ใบสั่งซื้อ (PO)
จัดซื้อ → ใบขอซื้อ (PR), ใบสั่งซื้อ (PO)
จัดซื้อ
รับเข้าสินค้า (GR) → เข้า Quarantine
คลังสินค้า → รับเข้าสินค้า (GR)
คลัง
QC ตรวจรับ → หัวหน้า QC อนุมัติ
QC → ตรวจรับ · ผ่าน = Lot Released · ไม่ผ่าน = Blocked
QCหัวหน้า QC
ใบเบิก → จ่ายเข้าห้องผลิต
คลังสินค้า → ใบเบิก · เบิกได้เฉพาะ Lot ที่ Released (FIFO) + อนุมัติใบเบิก
คลังฝ่ายผลิตขอเบิก
สร้างใบตวงสาร คุณอยู่ตรงนี้
คลังสินค้า → ใบตวงสาร (ชั่งตวงสาร) → ปุ่มสร้าง · URL /warehouse/weighing
เลือก SO → ระบบเติมวัตถุดิบจาก BOM (สารรวม 1) + Lot/รอบของ SO → กรอกน้ำหนักที่ชั่งได้ต่อถัง, เครื่องชั่ง, ลำดับการผสม, น้ำหนักรวมภาชนะ (บังคับ) → บันทึก
คลังฝ่ายผลิต
ระบบเทียบกับค่ามาตรฐานให้ทุกแถว (เกณฑ์เริ่มต้น ±2%) — ถ้าเกินเกณฑ์จะเตือนตั้งแต่ตอนบันทึกว่า "QC จะทวนสอบไม่ผ่าน"
ระบบยังไม่ได้ผูกใบตวงสารกับ Lot ที่เบิกจากคลัง และไม่ได้เช็คว่าเบิกของแล้วหรือยัง — เส้น B ต้องทำให้ครบตามขั้นตอนเอง

ช่วงที่ 2

QC ทวนสอบใบตวงสาร (สถานะ "รอ QC ทวนสอบ")

QC เปิดใบ → ติ๊ก "ลำดับการผสมถูกต้อง" → ตัดสิน
หน้าเดิม /warehouse/weighing?tab=pending → ไอคอนดินสอ → ส่วน "QC ทวนสอบ" · หรือเข้าจากการ์ด "ใบตวงรอทวนสอบ" บนแดชบอร์ด QC
QC / หัวหน้า QC / admin
ผู้ที่บันทึกใบนั้นทวนสอบใบของตัวเองไม่ได้ ต้องให้ QC อีกคนเป็นผู้ทวนสอบ
ทวนสอบผ่าน
เทลงเครื่องผสมได้
กดได้เฉพาะเมื่อทุกแถวอยู่ในเกณฑ์
↓ ไปช่วงที่ 3
ไม่ผ่านการทวนสอบ
ต้องใส่เหตุผล → เปิด NCR เข้ากล่องงานของ QA
ใบนี้ล็อก แก้ไม่ได้ · QA → NCR
QA
↺ ชั่งใหม่เป็นใบตวงสารใบใหม่ (Lot/รอบเดิม) → กลับไปรอ QC ทวนสอบ

ช่วงที่ 3

ผ่านแล้วไปไหนต่อ

1. ติ๊กรอบผสมของห้องผสม
ฝ่ายผลิต → แผนผลิต (/production/plan)
ฝ่ายผลิต
ด่าน: ห้องผสมเพิ่มรอบได้เมื่อใบตวงสารทวนสอบผ่านแล้ว
2. บันทึกผลิต (FM-PD-17) + Loss
ฝ่ายผลิต → บันทึกผลิต, Loss Monitor
ฝ่ายผลิต
ด่าน: SO ที่ยังมีใบตวงสารที่ไม่ผ่านการทวนสอบ จะบันทึกผลิตไม่ได้
ช่องโหว่: SO ที่ไม่มีใบตวงสารเลยยังบันทึกผลิตได้ (ระบบนับเฉพาะใบที่ยังไม่ผ่าน)
3. QC ตรวจระหว่างผลิต (Bulk / ระหว่างบรรจุ)
QC → ตรวจระหว่างผลิต (/qc/in-process) · ไม่ผ่าน → NCR
QC
ตอนนี้ผลไม่ผ่านไม่ได้ไปกันการปล่อย Batch (ยังรอตัดสินว่าจะบล็อกหรือไม่)
4. รับ FG เข้าคลัง → ได้ FG Lot สถานะ "รอ QC" (Quarantine)
คลังสินค้า → รับ FG เข้าคลัง · เลือก SO ที่ยังไม่ปิด + ผูกสูตร · เลข Lot ระบบออกให้
คลัง
5. QC ตรวจ FG → หัวหน้า QC อนุมัติ → QC Passed
QC → สถานะ Lot → คิว FG → สร้าง/เปิดใบตรวจ FG · ไม่ผ่าน = FG Hold/Blocked
QCหัวหน้า QC (คนละคนกับผู้เสนอ)
6. QA ปล่อย Batch → Released / Available
QA → ปล่อย Batch · QC Passed ยังขาย/จองไม่ได้จนกว่า QA จะปล่อย
QA
7. ใบเหลือง (FM-PD-20) → ใบส่งของ (DO) → ส่งลูกค้า
ฝ่ายผลิต → ใบเหลือง · คลังสินค้า → ใบส่งของ (DO) · หยิบได้เฉพาะ Lot ที่ QA ปล่อยแล้ว (FIFO)
ฝ่ายผลิตคลัง
  • ช่องสีฟ้า = ด่านที่ระบบบังคับจริง (เช็คจากโค้ด API) · ช่องสีแดง = ช่องโหว่ที่ระบบยังไม่กัน
  • เมนูใบตวงสารเห็นเฉพาะบัญชีที่มีสิทธิ์คลังสินค้าหรือฝ่ายผลิต — ถ้าบัญชี QC มองไม่เห็นเมนู ให้เข้า URL ตรง หรือเพิ่มสิทธิ์ดูคลังให้บทบาท QC
  • ลำดับช่วงที่ 1 และขั้นที่ 7 อ้างอิงแผนภาพ End-to-End Process Flow (ปรับปรุง 30 ต.ค. 2569)
